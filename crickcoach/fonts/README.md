# Fonts for the certificates

The certificates are drawn on the server, so the fonts travel with VANSH.
Both families are under the SIL Open Font License 1.1, which allows
bundling them with software. The licence texts are next to the fonts.

- DM Serif Display (Regular, Italic), from https://github.com/google/fonts/tree/main/ofl/dmserifdisplay
- Lato (Regular, Bold), from https://github.com/google/fonts/tree/main/ofl/lato
